# M0: Monorepo and local dev environment

Branch `m0-monorepo-dev-env`. Goal: one command brings up everything needed to develop; CI runs lint and tests.

## What is in this PR

- **Root workspace:** `pnpm-workspace.yaml`, `package.json`, `.editorconfig`, `.node-version` (Node 22), `Makefile` with every target from `CLAUDE.md`, `.pre-commit-config.yaml`.
- **Dev services** (`infra/docker`): images pinned; host ports configurable via `DB_PORT`, `REDIS_PORT`, ... in `.env`; role script applies extensions, grants and default privileges to `template1` as well as the dev database so the pytest database inherits them.
- **Django API** (`apps/api`): Python 3.12 via uv, Django 5.2 LTS, GeoDjango, Django Ninja at `/api/v1` (docs at `/api/v1/docs`, OpenAPI 3.1), psycopg 3, Celery, django-environ settings split into base/dev/test/prod, three DB aliases with a migrations router, GDAL/GEOS auto-detection on macOS.
- **`common` app:** `UUIDv7Model`, RFC 9457 problem JSON (Ninja and Django-level handlers), keyset cursor pagination, `/health` and `/.well-known/precisecapture` (root and under `/api/v1`), `common.ping` Celery task.
- **Tooling:** ruff, mypy strict with django-stubs, pytest-django, factory_boy, pre-commit.
- **CI:** GitHub Actions job for the API against PostGIS and Redis service containers (lint, migrations check, tests incl. the Redis integration test) and a web job that runs once workspace packages define scripts.
- **Docs:** spec/plan/notes inconsistencies found at kickoff fixed; nine decisions recorded in `docs/DECISIONS.md`; README quick start updated.

## Decisions and open points for Ben

- **MinIO images are no longer publicly pullable** (Docker Hub and quay.io both deny). The compose file pins the release cached on Ben's Mac; a fresh machine cannot pull it. Proposed swap before M7: `versity/versitygw` or `rustfs/rustfs`. See `docs/DECISIONS.md`.
- PostGIS image is `imresamu/postgis:16-3.5`, the multi-arch build of the official Dockerfiles (official image is amd64 only).
- `.env` files must not contain inline comments (django-environ keeps them as part of the value).
- The repository on GitHub is public; the handover guide asked for private.
